Every build is self-contained. Windows, macOS and Linux all ship as PyInstaller single-file binaries, so no Python installation is needed.

The full .zip contains the binary, the matching config file and the readme — that is the recommended first download.

macOS: if Gatekeeper blocks the unsigned binary, right-click it and choose Open, or run xattr -d com.apple.quarantine MinecraftBotClient-en. The published macOS build is Apple silicon (arm64); builds match the architecture of the Python used to produce them. Linux: run chmod +x MinecraftBotClient-en once before launching.

Keep the config beside the binary. config.en.json must sit in the same folder as the client, otherwise the built-in defaults are used.

Features

Implemented in the client itself. No mods, no game assets, no launcher.

Version support
Auto-detects the server protocol for any version between 1.8 and 26.2. Unlisted versions inside a range map to the nearest known protocol ID.
SRV records
Resolves _minecraft._tcp.<domain> automatically, so a bare domain works without specifying a port.
Bilingual UI
Chinese or English, selected from the executable suffix: -zh or -en.
Autocomplete
Vanilla-style grey inline preview on . or /. Tab completes and cycles, arrow keys and the mouse wheel browse suggestions.
Chat and commands
Plain text is sent as chat, a leading / sends a server command, a leading . runs a client command that never reaches the server.
Client commands
Ten command families covering connection, logging, spam, walking, eating and live config edits. The legacy // prefix still works.
Human-like actions
Head turns and arm swings follow Bézier trajectories with randomised delays, mimicking real mouse movement.
Multi-bot mode
Launch 20, 100 or more bots from the config with unique random usernames, staggered joins and automatic /register or /login after each bot connects. Broadcast chat to the whole group with .say.
Auto-walk
Random roaming or custom waypoints. Movement stops automatically on damage or death.
Auto-eat
Attempts to eat whenever health falls below a configurable threshold. Toggled at runtime with .eat on and .eat off.
Proximity alerts
Reports nearby players and missing blocks ahead. Printed locally, invisible to other players.
Auto-spam
Configurable rate and message list, persisted to the config file so it survives restarts.
Session logging
Writes a timestamped .log file into log/ for every session while logging is enabled.
Remote checks
Displays remote version and announcement text verbatim on startup. Skip both with fast_start.
Offline mode
Designed for online-mode=false servers. Premium account support is still in development.
Cross-platform
Windows, macOS and Linux, distributed as a native single-file binary built with PyInstaller on each OS. Autocomplete, history and mouse-wheel input work on the Windows console and on POSIX terminals alike.

FAQ

    


    

      

        Can I join a premium (online-mode) server?
        

          
No. The client runs in offline mode and targets servers with online-mode=false. A premium server rejects the login with an auth failure, which is expected behaviour.

          
Premium account support is still in development.

        

      


      

        Does it run on macOS and Linux?
        

          
Yes. Since v2.0.0 the client ships native single-file builds for Windows, macOS and Linux. Interactive input — autocomplete, history, arrow keys and the mouse wheel — is implemented for both the Windows console API and POSIX terminals, so the console behaves the same on every platform.

          
On macOS and Linux make the binary executable once with chmod +x MinecraftBotClient-en, then run ./MinecraftBotClient-en. Builds are produced per platform by running python build.py on each OS, because PyInstaller cannot cross-compile.

        

      


      

        My antivirus flags the executable
        

          
PyInstaller single-file executables unpack themselves at runtime, which heuristic scanners commonly flag. This is a false positive.

          
Either whitelist the folder or run the project from source with python main.py.

          
On macOS, Gatekeeper blocks unsigned binaries the same way. Right-click the file and choose Open, or run xattr -d com.apple.quarantine ./MinecraftBotClient-en.

        

      


      

        Can I run many bots at once?
        

          
Yes. Set multi_bot_enabled to true and choose a bot_count — 20, 100 or more. Each bot gets its own random username and connection, joining with a configurable delay between them.

          
With bot_auth_enabled on, every bot automatically sends your /register or /login command after joining, so it works on AuthMe-style servers. The console then controls the group: .status, .say <text> and .exit.

        

      


      

        Do I need to install Minecraft?
        

          
No. MBC speaks the Minecraft protocol directly and ships without game assets — no client jar, no textures, no launcher. That is why the whole client fits in a single 17 MB file.

        

      


      

        How do I change the server without editing JSON?
        

          
Use the client commands. .esc leaves the current server while keeping the client open, and .connect reconnects with the current config.

          
To retarget, run .config server_address mc.example.com and then .connect.

        

      


      

        Where are the log files?
        

          
In a log/ folder beside the executable. Each session creates a new timestamped file such as MBC-2026-09-04_22-55-29.log while logging is enabled.

        

      


      

        How do I know my server version is supported?
        

          
Anything from 1.8 to 26.2 works. Type the version into the lookup box in the protocol section, or just set minecraft_version in the config — the client probes the server for its real protocol before login.

        

      


      

        Startup failed. What should I check?
        

          
In order: is the config file in the same folder as the executable, is server_address reachable with the right port, does the server allow offline-mode clients, and is a restricted network blocking the version check?

          
For the last one, set fast_start to true. The client prints a full traceback, and the same text is written to the session log when logging is enabled.

        

      


      

        Is this allowed on public servers?
        

          
That depends on the server. Many ban automated clients outright. MBC is published for testing and development — check the rules before using it anywhere.
